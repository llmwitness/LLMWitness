# AgentTrace Support & Community Guidance

Welcome to the AgentTrace support portal. This document details how to obtain assistance, ask questions, and report operational issues.

---

## Support Channels

### 1. GitHub Issues (Bug Reports & Feature Requests)
For technical bugs, unexpected errors, or feature requests:
- **Bug Reports**: Open a [Bug Report](https://github.com/Vinayakdata/AgentTrace/issues/new?template=bug_report.md).
- **Feature Requests**: Open a [Feature Request](https://github.com/Vinayakdata/AgentTrace/issues/new?template=feature_request.md).

### 2. GitHub Discussions
For general architectural questions, implementation patterns, and best practices, use [GitHub Discussions](https://github.com/Vinayakdata/AgentTrace/discussions).

### 3. Security Vulnerabilities
To privately disclose security vulnerabilities or PII engine bypasses:
Email: `security@agenttrace.dev`

---

## Community & Enterprise SLAs

- **Community Support**: Provided on a best-effort basis by maintainers and community contributors.
- **Security Response SLA**: Acknowledgment within 24 hours; initial triage within 72 hours.
