# Target: maintain LLMWitness Community

LLMWitness Community is a single-user localhost development toolkit. Preserve these boundaries:

- Describe redaction as best-effort pattern scrubbing.
- Describe receipts as local and tamper-evident, never immutable storage or WORM.
- Do not claim compliance, production readiness, complete telemetry, streaming, or universal performance.
- Keep Cloud and Enterprise implementation out of this public repository.
- Preserve UUIDv7 correlation across the Python SDK, gateway, ingestion service, JavaScript bridge, and extension.
- Add regression tests for security and correctness fixes.
- Never publish packages, push commits, create tags, or enable automatic publishing without explicit maintainer authorization.
